# HR Analytics Dashboard

## 📌 Overview
An interactive HR Analytics Dashboard built in Power BI to analyze employee attrition, workforce distribution, and key HR metrics.

## 🛠 Tools Used
- Power BI
- Power Query
- DAX
- Excel

## 📊 Key Features
- Employee KPIs
- Attrition Analysis
- Department-wise Insights
- Salary & Age Analysis
- Interactive Filters
